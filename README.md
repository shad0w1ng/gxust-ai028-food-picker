# 柳州今天吃什么 · GXUST AI导论028

一个面向柳州本地的随机美食推荐网页。页面会尝试识别访问者当前所在的县区，从对应的美食池中随机抽取一餐；抽中后会在页面内自动加载腾讯地图，在当前位置 3 公里内按距离优先展示售卖该食物的店铺，无需跳转页面。

> 本项目为 **GXUST AI导论028** 课程实践作品，主要用于展示浏览器定位、行政区边界判断、随机推荐和地图检索的组合应用。

无需注册或登录。自动定位需要浏览器授权，也可以手动选择柳州市的区县。

## 功能

- **城区识别**：使用浏览器 Geolocation API 获取位置，并在本地通过柳州市行政区边界判断所在县区。
- **手动兜底**：定位被拒绝、超时或当前位置不在柳州时，可手动选择全市或任意区县。
- **分区随机池**：柳州全市默认池 36 种美食，各区县池为 31～32 种。
- **随机去重**：同一轮推荐中不会连续抽到同一项。
- **按名称找店**：抽中食物后自动在当前页加载腾讯地图，携带找店关键词、当前位置和 3 公里搜索范围，并按距离优先展示附近店铺。
- **页面内嵌地图**：地图支持官方“地图 / 列表”切换，可在不离开页面的情况下查看店铺；同时保留“新窗口打开”入口。
- **找店关键词映射**：对“番茄鸡蛋盖饭”“黄焖鸡米饭”等长菜名自动转换为“盖饭”“黄焖鸡”等更适合地图搜索的关键词，减少无关结果。
- **位置持续更新**：定位成功后通过 `watchPosition` 更新坐标，之后切换城区也不会把搜索中心错误地改回行政区中心。
- **移动端适配**：适配手机和桌面尺寸，无横向溢出。
- **公开分享**：内置系统分享与复制链接能力。
- **隐藏水印**：页面包含低透明度斜向 “GXUST AI导论028” 水印及对应的页面元数据。

## 实现说明

1. 浏览器通过 Geolocation API 返回 WGS84 坐标。
2. 前端将坐标转换为 GCJ-02，以便与地图数据对齐。
3. 在本地对行政区多边形执行点在多边形内判断，识别当前县区。
4. 随机池由该区域的本地特色美食与常见餐食合并、去重后组成。
5. 抽中食物后，生成腾讯地图搜索链接，关键词为食物名称或更准确的找店关键词，中心点为当前位置，半径为 3000 米。
6. 搜索页嵌入当前网页，自动展示地图标记和店铺信息；地图结果按距离从近到远排列。

## 数据与隐私

- 城区识别逻辑只在浏览器本地参与计算，本项目的服务器不接收或存储位置。
- 自动加载附近店铺时，会将当前位置和食物关键词提交至腾讯地图，用于返回附近结果；相关信息由腾讯地图按其服务条款处理。
- 随机池是课程项目整理的离线数据，**不是实时商家名录，也不包含商家价格或库存**。
- “地图看附近”和“新窗口打开”会跳转到腾讯地图，实时商家信息以地图页面为准。
- 行政区边界数据来自 DataV.GeoAtlas；地图服务由腾讯地图提供，相关数据和接口遵循各自服务条款。
- 页面没有接入第三方统计、广告或用户追踪脚本。

## 已知限制

- 自动定位需要 HTTPS 或 localhost；普通 `file://` 打开时可能无法请求定位或读取本地 JSON。
- 行政区边界与 GPS 精度会影响边界附近的位置判断。
- 腾讯地图页面的首次加载速度受网络状况影响。
- 浏览器扩展或第三方 Cookie 限制可能阻止内嵌地图加载，此时可使用“新窗口打开”。
- 美食池并非实时团购数据；团购平台通常不提供未经授权的公开抓取接口。
